Day 12:
Technique: Privilege Escalation via SUID Binary

Initial Access:
- User: www-data
- Shell obtained via WebDAV PHP webshell

Enumeration:
- SUID binaries discovered using:
  find / -perm -4000 -type f 2>/dev/null

Exploitable Binary:
- /usr/bin/find
- SUID bit set
- Owned by root

Exploitation Method:
- Executed /bin/sh using find -exec option
- Spawned root shell

Result:
- Initial user: www-data
- Final user: root

Proof:
- Successful execution of id
- Read access to /etc/shadow
